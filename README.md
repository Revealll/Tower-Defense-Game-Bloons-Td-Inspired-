# Tower-Defense-Game-Bloons-Td-Inspired-
Tower Defense Game built using TypeScript using Object Oriented Programming

## Features
- Tower Defense Gameplay (You Vs Another)
- Supports Multiplayer From Different devices (FireBase)
- Basic pathing for Bloons
- Towers that can spawn and attack enemies
- Miniature Sign In (guest only as of writing)

## How to Run
1. Install Dependencies
2. Run Using Live Server
3. Paste the Web Link on a Different Device
